# DroidDeck 中文版 v0.5.0-zh.1

基于上游 [DroidDeck 0.5.0](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.5.0)。包名 `com.droiddeck.launcher.zh`，可与原版共存；versionCode 15。

## 上游 0.5.0 主要变化
- **Meta Quest 3 / 3S SteamVR**：标准 APK 即可，自动检测头显，OpenXR 沉浸式 SteamVR（追踪、Touch、触觉、仪表盘）；平板游戏支持手势追踪。实验性支持 Quest 2。
- **XR 眼镜**：VITURE、RayNeo、XREAL；眼镜刷新率/3D/亮度等可调；支持 Play SteamVR、Joy-Con 作手、手机摄像头追踪；头显跟随虚拟屏（设置 → 智能眼镜）。
- **Google Cardboard** 与更多 VR/空间校准相关能力。
- Steam/会话、存储、GPU、启动动画等方面的多项改进与修复（详见上游发布说明）。

## 中文版改动
- 合并上游 0.5.0；上游已自带大部分简体中文翻译（约 725 条新字符串含汉字），保留「DroidDeck 中文版」应用名。
- **bwrap 套接字**：上游改为按 `packageName` 派生，中文版自动使用 `com.droiddeck.launcher.zh.bwrap`，不再硬编码。
- 保留：内置 Turnip / Decky / Noto Sans SC 与 CJK 字体配置、`BundledComponents` 离线驱动、应用内更新指向本仓库 `catalog` 分支、release-zh 与 fork 门禁。
- 构建：沿用上游 bullseye 编译器回退逻辑，并保留从上游拉取 Debian 镜像；保留 Bundle GPL 步骤，并纳入上游新增的 GOG Galaxy companion 构建。

## 未测试
- 未在真机/头显/眼镜上验证；SteamVR、智能眼镜、Cardboard、从 0.4.0-zh.1 应用内更新均未测。
