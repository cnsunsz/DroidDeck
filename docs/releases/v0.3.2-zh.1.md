# DroidDeck 中文版 v0.3.2-zh.1：同步上游 0.3.2

基于上游 [DroidDeck 0.3.2](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.3.2)（提交 `a58b0ac`），保留中文版既有改动，并打通应用内更新。

### 升级方法

- **直接覆盖安装 v0.3.1-zh.1**：包名 `com.droiddeck.launcher.zh` 与签名不变，versionCode 升到 13。应用数据、Linux 运行时和 Steam 登录状态都会保留。
- 也可在应用的「更新」页检查并安装（本版本起指向本仓库的 Releases）。

### 上游 0.3.2 更新内容（摘要）

**功能**
- **保持下载继续**：Steam 下载时可在 Android 休眠后继续。
- **原生 Steam 休眠**，支持云存档与唤醒动画。
- **Adreno 6xx** 支持（含 Adreno 650，如 Retroid Pocket 5）。
- SD 卡与外置存储可作为完整 **Steam 游戏库**。
- 每个游戏的 **Windows 组件**，以及自动依赖推荐；可安装 XNA、PhysX、Games for Windows Live、MSXML 等而无需跑原安装程序。
- 可选 **Force SSBS**（在支持的 CPU 上用于 ARM64 Proton）。
- 更详细的 **设备报告**；**应用缩放** 预设 75%–150%。
- 文件管理器可直接浏览 Linux 文件系统。
- **语言**设置，Steam 界面会跟随所选语言。
- 可选的调试/自动化工具。

**改进**
- Steam 与游戏分在两套 Xwayland 上运行（更接近 SteamOS）。
- 新安装默认使用 DirectAudio，音频卡顿/欠载有改善。
- Steam 会保留对添加游戏快捷方式的修改。
- **在大于 1080p 的屏幕上，Steam 使用完整会话分辨率**（修复手机上被画成 1080p 带黑边的问题）。
- 小屏幕与长翻译文案的布局改进。
- **Steam 与 Linux 应用用 Android 系统字体显示中日韩泰等字符**（设备字体绑定 + fontconfig）。
- 从 Android 前端启动的会话结束后会回到该前端。

**修复**
- MangoHud 功耗/剩余时间翻倍；SD 卡安装缓慢或卡住；游戏卡在 Steam 黑屏加载后其实已在运行；显存泄漏；分辨率预设改变屏幕比例；Steam Deck 模式下 16:9 拉伸；移除「强制游戏窗口全屏」旧方案（现已分 Xwayland）等。

完整英文说明见[上游 0.3.2 发布页](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.3.2)。

### 手机全屏

上游 0.3.2 已基本覆盖此前「手机不全屏」的主要原因：

1. Steam 在大于 1080p 的会话里曾固定画成 1920×1080 并留黑边，现已改为使用完整会话分辨率。
2. 分辨率预设（720p/900p/1080p）会保持手机面板的宽高比（例如 20:9），不再被压成 16:9。
3. 设置里已有「全屏」开关（默认开启），用于隐藏 Android 状态栏和导航栏；会话本身也是沉浸式全屏并允许短边刘海区域绘制。

本版本额外让**启动器全屏**在有刘海/挖孔的手机上同样使用短边裁切模式，避免被裁切区域挤出黑边。Steam Deck / 横屏平板行为不变。若仍看到黑边，请在会话的「分辨率」中选「匹配屏幕」，或按游戏需要调整图像缩放。

### 中文版改动

- **应用内更新指向本仓库**：`com.droiddeck.launcher.zh` 从 `cnsunsz/DroidDeck` 的 `catalog` 分支读取 `catalog.json`（发布流程自动更新），校验本分支签名证书 `cc15df97…`，并只允许下载本仓库 Releases 里的 APK。原版包名仍走上游 DroidDeck-CI 目录，互不影响。需要授予「安装未知应用」权限（与上游相同）。
- **完整简体中文**：合并上游 0.3.2 的新字符串与语言资源；应用名仍为「DroidDeck 中文版」。
- **预装组件**（与 zh.1/zh.2 相同）：Turnip 驱动、Decky Loader、Noto Sans SC 字体。上游现已绑定 Android 系统字体作 CJK 回退；本分支仍附带 Noto Sans SC，在系统字体不完整时作为兜底。
- Steam 界面语言改为跟随应用的「语言」设置（上游能力）；不再单独写入默认 `registry.vdf`。
