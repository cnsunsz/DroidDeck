# DroidDeck 中文版 v0.7.1-zh.1

基于上游 [DroidDeck 0.7.1](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.7.1)。包名 `com.droiddeck.launcher.zh`，可与原版共存；versionCode 19。

这是针对上游 0.7.0 的修复版。完整细节见[上游发布说明](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.7.1)。

## 上游 0.7.1 主要变化
- 新增 **Scarlet snow（猩红之雪）** 浅色主题；画面可左右对齐（手柄指针和触摸会跟随，也适用于眼镜）。
- **GOG** 会安装已拥有的 DLC，搜索覆盖整个 GOG 目录；并修复自 0.6.0 起已拥有游戏丢失的问题。
- 修复 0.7.0 回归：Steam 卡在 “Processing install script” 或下载不完、退出后黑屏并出现 “Abort game”。
- 修复从 DroidDeck 启动的游戏卡在 Steam 启动画面、退回 Steam 后无限加载。
- 去掉副屏仪表盘的通知页，不再申请读取通知。
- 修复 Ubuntu 26.04 运行时后 PowerVR（Pixel 10 Pro / Pro XL）上 Steam 和游戏变成灰阶。
- 修复 EasyAntiCheat 游戏无法启动、Steam 里选的 Proton（如 Experimental）被改回 DroidDeck-Proton、Steam 未就绪时商店应用提示未安装 Proton。
- 修复 ARM64 前缀被写入 x64 系统 DLL 后出现 `c000007b`；Adreno 上 AppImage / Flatpak / Snap 走系统内存渲染；部分 Linux 模拟器启动卡住；桌面会话里 Firefox 标签崩溃或浏览器卡死。
- 另有弹窗点击无效、相对鼠标误把点击当成移动、13 GB 及以下内存卡顿、仪表盘帧图跳动等修复。

## 中文版改动
- 合并上游 0.7.1；采用上游已有的简体中文翻译，并将应用名保持为「DroidDeck 中文版」；补全上游尚未翻译的字符串（含「猩红之雪」主题说明）。
- 保留：内置 Turnip / Decky / Noto Sans SC 与 CJK 字体配置（与上游系统字体挂载并存）、`BundledComponents` 离线驱动、应用内更新指向本仓库 `catalog` 分支、release-zh 与 fork 门禁。
- 未重新引入旧的 `MainActivity.kt`（上游为 `FrontEndActivity`，`MainActivity` 仅作为清单中的 activity-alias）。
