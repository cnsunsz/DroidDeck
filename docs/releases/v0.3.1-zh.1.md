# DroidDeck 中文版 v0.3.1-zh.1：同步上游 0.3.1

基于上游 [DroidDeck 0.3.1](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.3.1)（提交 `31ea194`），保留 zh.2 的全部中文版改动。

### 升级方法

- **直接覆盖安装 v0.3.0-zh.2（或 zh.1）**：包名 `com.droiddeck.launcher.zh` 和签名都没有变，versionCode 升到 12。应用数据、Linux 运行时、Steam 登录状态和游戏都会保留。
- 原版 DroidDeck 仍然无法被本版本覆盖（签名不同），两者可以同时安装。

### 上游 0.3.1 更新内容（摘要）

**Steam**
- 可以从 ZIP 文件导入 Decky 插件，插件需要的远程二进制文件会校验 SHA-256，并替换已安装的同名插件。
- Steam 的“互联网”页面会显示 Android 的 Wi-Fi 和移动网络连接。授予位置权限后，还能显示网络名称和附近的网络。
- 可以把 Android 剪贴板中的文字粘贴到 Steam 会话。
- “组件”中选择的 Proton 与 Steam 的默认兼容性工具保持同步，可用的版本会标记为“兼容”。有 Valve 推荐设置的 Windows 游戏默认使用该设置，除非你为游戏另选了兼容工具。

**兼容性与性能**
- Proton 游戏可以选择 **esync**、**fsync**、实验性的 **ntsync** 或 **wineserver** 同步方式，用来弥补 Android 内核缺少的支持。新安装默认使用 esync，已有的选择会保留。
- droiddeck-esync 包会按 Valve、GE-Proton、CachyOS Proton 的具体版本自动匹配并下载；没有对应包时由 droiddeck-fsync 代替。
- 仅有 Linux 版的 x86 Steam 游戏可以通过 Steam 自带的 FEX 和 Steam Linux Runtime 运行，支持手柄和本机显卡驱动。缺少的依赖会通过 Steam 下载。
- .NET 和 Godot 游戏在 FEX 下会自动应用启动修复（包括《杀戮尖塔 2》需要的设置），每个游戏单独的设置会保留。

**显示与画面效果**
- 实时图像缩放：AMD FSR 1、Snapdragon GSR 及其画质模式、NVIDIA NIS、线性和最近邻过滤，以及锐化。
- 新的“效果”页面：预设、FXAA、卡通描边、CRT、NTSC、伪 HDR；高级选项包括锐化、去色带、亮度、对比度、伽马和饱和度，设置会在会话之间保留。
- DirectX 9–11 游戏可设置各向异性过滤和纹理锐度，在下次启动游戏时生效。
- 开始会话前的统一“分辨率”菜单：预设尺寸、自定义和“匹配屏幕”。分辨率、图像缩放和全屏兼容性分开设置。

**操作与会话**
- 支持 Android 画中画，可以手动打开，也可以在离开已就绪的会话时自动进入；返回后恢复第二屏幕控制。
- 快捷开关可以隐藏或恢复屏幕控制。“触控关闭”会忽略游戏画面上的触摸，Android 控件仍可使用。
- 可选的游戏振动，以及屏幕上的 Steam、快捷菜单和键盘按钮。
- Steam 会话设置分为显示、控制、游戏、音频、会话和 Steam 几个标签页；会话菜单以手柄页开头，第二屏幕模式有单独的页面。
- “停止”旁边新增 Steam 主页和快捷菜单的快捷按钮。
- 返回键双击的判定时间恢复为 500 毫秒，更容易打开快捷菜单。

**应用与启动器**
- 可以为已安装的 Steam 游戏和添加的游戏创建 Android 桌面快捷方式。
- 可以为 Android 前端导出每个游戏的 `.droiddeck` 启动文件和 Steam 图标，并可随游戏库变化自动同步文件夹。
- 可以导入 x86 AppImage，并通过 FEX 运行 x86 Linux 脚本和程序。添加的应用有“使用 FEX：自动/开/关”选项；从 GitHub 导入时，如果没有 ARM64 版本，可以使用 x86_64 AppImage。
- OpenNOW 等使用 Vulkan Qt Quick 的 AppImage 改用 Wayland，避免 X11 启动失败。
- 预览版更新会显示最近发布的更改，以及落后了多少个构建。
- Steam 页面新增空游戏库引导和 DroidDeck 字标，并可选择减少应用动画。
- Linux 文件管理器会自动为所选的游戏库添加书签。

**语言与日志**
- 上游新增简体中文、日语、韩语，以及台湾、香港、澳门繁体中文。
- 可选的“存储诊断”会在分享的会话日志中记录空间分配和存储耗时，便于排查 Steam 安装缓慢的问题。
- 会话日志会保留最后的输出；AppImage 或 FEX 程序启动失败或崩溃时，日志内容更详细。

**修复**
- 内核较旧的掌机上找不到 Steam 的 Deck 手柄。
- 在应用数据目录被链接的 ColorOS 设备上，实体手柄和屏幕手柄没有反应。
- 游戏振动发到手机而不是当前使用的实体手柄（屏幕控制或没有马达的手柄仍由手机振动）。
- 使用实体鼠标时，视角在屏幕边缘停止转动；需要锁定指针的游戏现在使用 Android 的相对指针捕获，打开菜单或画中画时会释放。
- 空闲休眠或 Android 恢复会话后，Steam 停留在黑屏。
- Steam 客户端更新中断后卡在“正在等待 Steam”：连续两次启动都没有画面时，会重新下载客户端，并保留游戏、设置和用户数据；“修复 Steam 客户端”也可以手动安排修复。
- “开始”与移除运行时同时进行时的冲突：移除时会显示进度并确认完成；首次设置会遵循所选的 Steam 渠道和已保存的界面缩放。
- GE-Proton 和 CachyOS Proton 因 Android 禁止访问 `/proc/sys/fs/file-max` 而无法通过 protonfixes 检查。
- DirectAudio 选择不正确、切换组件后残留不匹配的 FEX 辅助程序，以及 SD 卡上的 Steam 游戏库中 FEX 或其运行时无法执行。

完整的英文更新说明见[上游 0.3.1 发布页](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.3.1)。

### 中文版改动（从 zh.2 延续）

- **完整简体中文界面**：上游 0.3.1 新增和修改的 96 条字符串均已翻译。另外把 0.3.1 中写死在代码里的38 条英文提示（Decky 插件 ZIP 导入、画面效果预设名称、缩放滤镜和帧率选项、esync 包下载进度、会话结束提示等）改为资源字符串，并附中英文版本。简体中文界面沿用中文版自己的翻译，没有改用上游新加的简体中文翻译，以保持用词一致。
- **独立包名与签名**：`com.droiddeck.launcher.zh`，应用名“DroidDeck 中文版”（繁体中文、日语、韩语界面下也显示这个名称），可与原版同时安装。
- **预装组件**（版本与 zh.2 相同；上游 0.3.1 没有改动这些组件的版本要求）：Banners-Turnip 与 WinNative Turnip GPU 驱动、Decky Loader，以及中文字体 Noto Sans SC（Regular / Bold）。
- **Steam 中文字体修复**：每次启动会话时检查字体，必要时装进 Linux 运行时的 `/usr/local/share/fonts/droiddeck-zh/`，并写入 fontconfig 回退规则，Steam 大屏幕模式切换到中文后不会显示方块。手机语言为简体中文时，全新的 Steam 默认使用简体中文（不会覆盖已有设置）。
