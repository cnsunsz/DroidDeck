# DroidDeck 中文版 v0.3.0-zh.1

基于上游 [DroidDeck 0.3.0](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.3.0)（`main` 分支 `6f1fb46`）。

### 更新内容

- **完整简体中文界面**：新增 `values-zh-rCN`，覆盖上游 `values/strings.xml` 的全部 937 条字符串（含数组和复数形式）。另外把驱动、更新、Decky、存档、文件选择等界面中原本写死在代码里的约 80 条英文提示改为资源字符串，并附中英文版本。系统语言为简体中文时自动显示中文。
- **独立包名 `com.droiddeck.launcher.zh`**：应用名为“DroidDeck 中文版”，**可与原版 DroidDeck 同时安装**，数据互不影响。内部的 bwrap 套接字也改为独立名称，两个应用同时运行时不会冲突。
- **预装 GPU 驱动和 Decky Loader**：首次运行时，“自动”驱动模式会直接从 APK 中安装适合本机 GPU 的驱动组合，无需下载。Decky Loader 在无法访问 GitHub 时也能直接安装。应用安装前会校验 SHA-256，与在线下载使用同一套校验。一天后会照常在线检查更新的驱动。
- **独立签名**：使用本分支自己的发布密钥签名。以后的中文版更新可以直接覆盖安装。

### 安装说明

- 本版本**不能覆盖安装原版**：原版由上游私有密钥签名，任何第三方构建都无法沿用该签名。因此本版本改用独立包名，与原版并存。
- 应用内的“更新”页面仍读取上游的发布目录。上游 APK 的签名和包名与本版本不同，不会被安装。中文版的更新请到本仓库的 Releases 页面下载。
- 需要 Android 9+，以及 Adreno 730 或更新（或 8xx）的 GPU。Linux 运行时约 3 GB，首次运行时在线下载。
