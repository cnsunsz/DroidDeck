# DroidDeck 中文版 v0.7.0-zh.1

基于上游 [DroidDeck 0.7.0](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.7.0)。包名 `com.droiddeck.launcher.zh`，可与原版共存；versionCode 18。

本版一次同步了自 0.6.0 以来的上游 0.6.7、0.6.9 与 0.7.0。完整细节见各上游发布说明。

## 上游 0.7.0 主要变化
- **初步支持 Mali、PowerVR 和 Xclipse GPU**：自动检测并选择驱动（Mali 上可用 Mali 桥接与 Venus，其他平台使用开源驱动组合）。
- **副屏 KDE 桌面**：可在 Steam 或游戏旁边，于下屏运行桌面（与仪表盘、键盘+触控板、终端、Deck 握把并列）。
- **交换屏幕**：可在下屏游玩、上屏显示仪表盘或桌面；会话菜单中也可选择“将游戏显示在”。
- **与其他 PC 游戏应用共享 Steam 库**：可发现内置存储或存储卡上已有的 Steam 库，最多再添加四个库，可重命名或移除。
- 新增 **GameJolt** 库与商店、**Syncthing** 同步、低内存设备改进、可自定义手柄配置与预设、实体键鼠支持、动态壁纸等。

## 上游 0.6.7 / 0.6.9 摘要（相对 0.6.0）
- **统一游戏库**与以封面为主的卡片、新游戏详情页。
- 掌机更接近 **SteamOS**：Steam 亮度/音量滑条控制本机，音量键显示 Steam 指示器，长按返回可作为 QAM。
- **休眠更省电**（测试中挂起一夜约耗电 2%）；**Xbox Cloud Gaming**、**Battle.net** 商店。
- Linux 运行时改为 **Ubuntu 26.04 LTS**，Kubuntu Plasma 桌面可按需安装。
- **双屏掌机**（如 Retroid Pocket Duo、AYN Thor）将启动器分区和游戏内菜单放到副屏；0.6.9 修复无响应、抢回前台、面板丢失等问题。
- DroidDeck HUD、竖屏启动器与会话、性能与发热改进；Steam 不再每次启动都重启以导入游戏；过场动画与 x86-64 Steam 客户端修复等。

## 中文版改动
- 合并上游 0.7.0；采用上游已有的简体中文翻译，并将应用名保持为「DroidDeck 中文版」；补全上游尚未翻译的字符串（含新增的输入配置文案）。
- 保留：内置 Turnip / Decky / Noto Sans SC 与 CJK 字体配置（与上游系统字体挂载并存）、`BundledComponents` 离线驱动、应用内更新指向本仓库 `catalog` 分支、release-zh 与 fork 门禁。
- 未重新引入 0.6.0 合并时残留的旧 `MainActivity.kt`（上游已重命名为 `FrontEndActivity`，`MainActivity` 仅作为清单中的 activity-alias）。
- 构建：在重组后的 `build.yml` 中保留 `workflow_call`、Bundle GPL、从上游仓库拉取 Debian 镜像，并将 sign/packs/announce/catalog 限制在上游仓库。
