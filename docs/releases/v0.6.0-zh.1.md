# DroidDeck 中文版 v0.6.0-zh.1

基于上游 [DroidDeck 0.6.0](https://github.com/Droid-Deck/DroidDeck/releases/tag/0.6.0)。包名 `com.droiddeck.launcher.zh`，可与原版共存；versionCode 16。

## 上游 0.6.0 主要变化
- **Xbox / PC Game Pass** 实验性商店：微软账号登录、下载暂停续传、更新、校验与附加内容。
- **itch.io** 商店：API 密钥登录、库与商店货架；无 DRM 的 Windows 构建经 Steam/Proton 启动。
- **商店页改版**：各商店 Library/Store 标签、胶囊视图、LB/RB 切换、已安装游戏的 Play 按钮。
- **可配置触屏手势**：单击/双击/长按、一至三指拖动与捏合缩放，可映射动作并支持按游戏覆盖。
- **Steam Remote Play** 现可传输视频（以及音频与输入）。
- 以及 Steam/会话、GPU、智能眼镜（含 Rokid）、手部追踪分包、运行时修复等多项改进（详见上游发布说明）。

## 中文版改动
- 合并上游 0.6.0；补全上游未译的约 56 条新字符串；应用名仍为「DroidDeck 中文版」。
- 保留：内置 Turnip / Decky / Noto Sans SC 与 CJK 字体配置（与上游新增的系统字体挂载并存）、`BundledComponents` 离线驱动、应用内更新指向本仓库 `catalog` 分支、release-zh 与 fork 门禁。
- 构建：沿用 Bundle GPL 步骤与从上游拉取 Debian 镜像；纳入上游新增的 Xbox ARM64 后端与 add-on packs 构建。
